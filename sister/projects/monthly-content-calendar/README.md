# לוח תוכן חודשי

כלי אישי מקומי לתכנון רעיונות תוכן על פני לוח שנה חודשי, עם חגים ומועדים
ישראליים (2026–2027) מסומנים מראש.

## הרצה

```
cd content-calendar
npm install
npm start
```

לאחר מכן פותחים דפדפן בכתובת: http://localhost:3000

השרת קורא וכותב את הנתונים לקבצי JSON בתיקיית `data/` (ideas.json,
products.json, clients.json, holidays.json), ותמונות שמצורפות לרעיונות
נשמרות בתיקיית `data/images/`. כל עוד השרת רץ — כל שינוי בדף נשמר בפועל
בדיסק.

## מבנה

- `server.js` — שרת Express: משרת את הדף וחושף API לרעיונות, מוצרים,
  לקוחות, חגים והעלאת תמונות.
- `public/` — הדף עצמו (HTML/CSS/JS רגילים, בלי build step).
- `data/` — כל הנתונים השמורים.

## הרחבות עתידיות (לא בגרסה הזאת)

- חיבור למכונות תוכן אוטומטיות שמייצרות הצעות רעיונות.
- הוספת טווח שנים נוסף לחגים (`data/holidays.json`).
