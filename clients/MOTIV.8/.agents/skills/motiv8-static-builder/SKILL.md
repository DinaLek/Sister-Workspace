# MOTIV.8 Static Builder

## Purpose

Create single-frame 4:5 static or diagnostic Instagram posts in the approved MOTIV.8 editorial system. A static post must communicate one specific observation, choice, or small prompt; generic motivational quotes are not acceptable.

## Required input

- audience situation and strategic role
- one insight or diagnostic question
- exact English copy and one gentle CTA
- visual brief and asset provenance
- intended primary metric

## Production rules

- Output 1080x1350, with 72px safe margins.
- Use the approved Ink `#302C28` as the default full-bleed ground for typographic statics, with warm-ivory `#FAF6EF` display type and one restrained semantic accent. A single low-contrast route line or soft light field is allowed in the background; never add a frame or inset card. Use warm beige or warm grey only when the feed rhythm or an explicit brief calls for it; white is not a default static ground.
- Use actual Instrument Sans Regular for all active copy, with a deliberate weight change only for a single semantic emphasis.
- Keep one big idea, sparse copy, generous whitespace, and at most one supporting device. Centre active copy horizontally and vertically; never add an outer frame, inset card, top title, temporary brand name, or page number.
- Use natural editorial imagery only when it adds meaning; never use generic AI portraits, staged smiles, or text baked into photography.
- Do not add format labels such as `REEL`, `CAROUSEL`, or `TOOL`.

## QA gate

Fail until corrected if the post is generic, unclear without context, overloaded, outside the palette, outside safe margins, typographically inconsistent, or missing a concrete takeaway or next step.

## Deliverables

Source/editable file, final 4:5 asset, review preview, caption, one CTA, QA result, and source/rights ledger.
