# MOTIV.8 Instagram Content Skill

## Purpose

Produce practical, calm, editorial Instagram content for MOTIV.8: content that turns overload into clarity and frames flexible progress as a capability rather than a planning failure.

The output must be usable by a designer or motion editor and ready for internal review. Do not invent a new visual language when the approved project references already answer the question.

## Required context

Before creating content, read:

1. `README.md`
2. `design-validation/visual-system-v3.md`
3. `design-validation/design-tokens.json`
4. `content-agent/weekly/2026-W36/review/pilot-visual-direction-v3.md`
5. `design-validation/feed/feed-preview-v3.png` and the relevant example posts when visual inspection is available.

If a newer approved visual-system or weekly direction exists, it supersedes older material. Preserve the approved direction unless the user explicitly asks for exploration.

## Core editorial rules

- Tone: warm, calm, smart, human, non-judgmental, practical.
- Convert overwhelm into one clear insight and one small action.
- Avoid productivity-guru language, shame, hustle, “no excuses,” and exaggerated transformation claims.
- One big idea per cover.
- Every carousel slide must advance a single practical teaching sequence. A reader should leave with enough detail to try the method today; a slogan, reframed affirmation, or repeated template is not value.
- Write creative copy in natural English. Use Hebrew only for internal production notes and user-facing summaries.

## Approved visual system

Use the project source files as the authority. The baseline system is:

- Background `#FAF6EF`; light surface `#FFFDF9`; sand `#EAD8C4`; lines `#E5D8CB`; ink `#302C28`.
- Accents: forest `#356A55`, terracotta `#C85F42`, gold `#D8A62B`, teal `#3C7F79`, plum `#8B586A`.
- Keep each frame 80–90% neutral. Use one semantic accent only; never make a saturated accent the dominant background.
- Instrument Sans for hooks, headings, and large display text. Inter for labels, numbers, explanations, and support text. Use weights 500, 600, 700.
- Prefer generous whitespace, 72px safe margins, thin quiet borders, 20px card radius, and 28px central-card radius.
- Use one supporting device per frame: route line, capacity bar, underline, note, short list, or choice row.

### Non-negotiable review rules

The approved Drive examples are the visual authority, not a generic interpretation of these tokens. Before making a new package, compare against the approved reference folder `1RboGd2NROnQxfJgcKaWay7qVd1zQQO8H` and use the actual approved Instrument Sans font files.

- Carousels and statics are clean, full-bleed 1080x1350 compositions: no outer frame, inset card, top title, temporary MOTIV.8 name, watermark, or slide number.
- Centre the active copy both horizontally and vertically. It must be large, light/regular Instrument Sans and fully inside the safe area. Do not use Inter, Arial, or a bold fallback for supporting copy.
- Use warm beige `#F4F0E7`/`#FAF6EF` for carousel sequences. Use the approved warm grey `#C9C6BE` as the default ground for static posts so they create a distinct feed rhythm; reserve beige statics for a deliberate feed-composition reason. Keep one background and one restrained accent within a carousel. Teal, forest and gold are emphasis only, never dominant backgrounds.
- A subtitle, divider, arrow, or action icon is optional. Add it only when it clarifies that specific slide; never add generic repeated decoration. Omit punctuation that merely separates display lines.
- A carousel is a practical sequence, not variations on its hook: every slide must add a distinct decision, step, example, or action. Do not recreate a previously approved topic or mechanism unless it is intentionally being revised.
- A photo-led Reel is full-frame photography with centred text over it. Motion must be continuous and tied to the image (for example, gentle window-light or leaf-shadow movement when the scene contains a window and greenery), never unrelated props or generic animated decoration.
- Reel attention comes from progressive text entrance, not hard slide transitions. Hold one subtle camera move across the whole video; never reset a zoom per beat or show all copy at once.

## Content mix

For a 10-post package, target:

- 3 documentary everyday-person images
- 2 nature/path metaphor images
- 1 object or environment image
- 4 typographic or diagram-led posts

For a five-post weekly package, use two photo-led covers and three graphic covers. Photography opens a story; it should not be used as the background for every carousel slide.

## Weekly package format

When asked for recurring content, return exactly 5 items unless the user asks otherwise. Choose each format for the teaching need (normally 2 Reels, 2 practical carousels, and 1 static post); do not fill a quota with thin ideas.

For every post include: working title, strategic role, format, hook/cover text, complete slide or scene plan, caption, one CTA, visual direction, asset needs, and risk/QA notes.

For Reels, target 7–15 seconds unless the teaching genuinely needs more. Make the useful idea clear in the first frame, then reveal the steps progressively so each beat earns attention. Motion should be a soft text reveal over one continuous background move. Avoid bounce, aggressive kinetic typography, rapid motivational cuts, unexplained decoration, and repeating the same visual behind every beat.

## Visual prompts and rights

When an image is needed, write a prompt that specifies documentary editorial photography, natural light, slightly grainy texture, partial/side/back view, neutral wardrobe/environment, and one small brand-color detail. Never request text rendered inside the image. Flag whether an asset is original, AI-generated, stock, or requires sourcing; do not imply rights clearance without evidence.

## QA before delivery

Check every package for:

- exactly 5 substantial items when a weekly package was requested;
- one clear idea per cover and no overcrowded frame;
- practical value, enough operational detail to act, and a distinct contribution from every carousel slide;
- visual mix and feed rhythm consistent with the approved system;
- neutral-dominant palette and one semantic accent;
- readable English, safe margins, and no text baked into generated photography;
- visually centred, approved Instrument Sans typography with no fallback, frame, title, page number, or unexplained punctuation;
- carousel slides whose copy matches the approved copy file exactly and whose sequence provides non-duplicative practical value;
- Reels sampled at each text beat, with image-led continuous motion and a verified final 30fps MP4;
- no claims, citations, or rights assumptions that were not verified;
- each post has a clear CTA, concrete production handoff, and a declared asset state (`draft`, `qa`, `approval-ready`, or `needs-attention`).

If a rule cannot be satisfied, mark the item `NEEDS DECISION` and state the smallest decision required. Do not silently compromise the approved system.

## Output style

Use concise Hebrew, clear tables only when they improve comparison, and production-ready wording. Separate strategy, copy, and visual execution. End with a short QA summary and a list of open decisions.
