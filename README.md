# Sister Workspace

סביבת העבודה המשותפת של Sister Marketing Agency.

## איפה שומרים מה

- `clients/` — ידע ועבודה לפי לקוח.
- `sister/` — הידע והעבודה של סיסטר עצמה.
- `operations/` — CRM, מכירות והצעות מחיר.
- `tools/` — סוכנים, אוטומציות וסקריפטים.
- `shared/` — תבניות וידע צוותי שאינם שייכים למותג מסוים.
- `archive/` — חומר היסטורי שנשמר לצורך שחזור.

## כלל העבודה

1. לפני עבודה על לקוח קוראים את `clients/<client>/client-context/` ואת README הלקוח.
2. חומר שהתקבל נשמר ב־`source`; טיוטות וקבצי עריכה ב־`working`.
3. תוצרים סופיים נשמרים ב־Google Drive. תיקיית `outputs` המקומית מכילה קישור בלבד.
4. פרויקט גדול וחד־פעמי נשמר תחת `projects/<project-name>/`.

- `[Client: שם הלקוח] תוצאה ברורה – YYYY-MM`
- `[Sister] תוצאה ברורה – YYYY-MM`
