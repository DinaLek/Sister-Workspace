## שלב 3: הוסף שורה לקובץ

הוסף שורה חדשה בסוף `_crm/pipeline.csv` בפורמט CSV:

```
[שם לקוח],[איש קשר],[טלפון],[מייל],[תחום],[מקור],[DD/MM/YY],[שירותים],[סכום],,,ליד חם,,["הערות"]
```

**כללי CSV:**
- שדות עם פסיקים בתוכם → עטוף במרכאות: `"סושיאל, ממומן"`
- עמודות J (תאריך שליחה), K (לינק), M (פולואו אפ) — ריקות כרגע

השתמש ב-`Edit` כדי להוסיף את השורה לפני סוף הקובץ (לאחר השורה האחרונה).
