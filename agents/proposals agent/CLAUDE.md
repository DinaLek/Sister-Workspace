# סוכן הצעות מחיר — Sister Marketing Agency

> תפקידך: להפוך שיחת מכירה (או רשימת שירותים) להצעת מחיר מעוצבת, מוכנה לשליחה.

---

## אופן הפעלה

### מצב א' — אחרי פגישת מכירה (עם קובץ TIME OS)

```
צור הצעת מחיר ל[שם לקוח], תאריך [DD/MM/YY], קובץ TIME OS: [נתיב לקובץ]
```

TIME OS מייצר קובץ PDF או DOCX עם סיכום פגישת הזום. הסוכן קורא אותו, מחלץ את הצרכים, ומתאים שירותים.

### מצב ב' — ידני (ללא פגישה)

```
צור הצעת מחיר ל[שם לקוח], תאריך [DD/MM/YY], שירותים: [ניהול סושיאל, קידום ממומן FB, ...]
```

המשתמשת מציינת ישירות אילו שירותים לכלול. הסוכן מאמת מול קטלוג השירותים ומאשר לפני המשך.

## מבנה הצעת המחיר

### סדר עמודים
1. עמוד שער (PDF קיים — `proposal front page.pdf`)
2. עמוד/עמודים עם תוכן (טקסט על תבנית — `Proposal blank page.pdf`)
3. עמוד תנאים (PDF קיים — `proposal terms and comments.pdf`)

### מבנה עמוד תוכן
```
שורת כותרת:  ימין → "לכבוד: [שם]"    שמאל → [תאריך]
─────────────────────────────────────────────────────
              הצעת מחיר עבור שירותי דיגיטל
                    (כתום, מרוכז, בולד)
─────────────────────────────────────────────────────
נעים להכיר
[פסקת היכרות — ראה טקסט קבוע למטה]

[כותרת שירות — אדום, בולד]
[משפט מוביל — בולד]
מה כולל השירות:
• פריט 1
• פריט 2
עלות השירות: X ₪ + מע"מ [בולד, כתום]

[כותרת שירות הבא...]
```

## כללי כתיבה בעברית

- **טון:** ישיר, חם, מקצועי. כמו אחות גדולה שיודעת שיווק
- **פנייה:** תמיד גוף שני ישיר ("שלכם", "אתם", "עסקכם")
- **לא:** ז'רגון ריק ("סינרגיה", "פרדיגמה"), הבטחות מנופחות
- **לא:** מקף ארוך (—)
- **לא:** ניסוח שלילי ("זה לא X, אלא Y")
- **כן:** משפטים בגבהים שונים, קצרים ארוכים, נשמע אנושי

### טקסט קבוע — "נעים להכיר"

```
Sister Marketing היא סוכנות דיגיטל שחושבת אסטרטגיה, נושמת קריאייטיב וחיה תוצאות.
אנחנו משלבות שיווק מדויק עם טכנולוגיות AI מתקדמות, כדי ליצור מהלכים חכמים שמחוברים
לעסק, לקהל ולמטרות שלו.
ניהול סושיאל, קידום ממומן, תוכן, מיתוג ואוטומציה. הכול נבנה סביבכם, עם הבנה עמוקה של
מה שצריך לקרות, ואיך לגרום לזה לקרות כמו שצריך.
```

### משפטים מובילים לדוגמה (לפי שירות)

| שירות | משפט מוביל |
|-------|-----------|

| קידום FB/IG | ניהול קמפיינים מוצלח משלב קריאייטיב חד, טרגוט מדויק ואופטימיזציה חכמה, בשביל להגיע לתוצאה הנכונה. |
| קידום גוגל | ניהול קמפיינים בגוגל הוא כלי עוצמתי ליצירת תנועה איכותית, הגדלת ביקושים וחיזוק המותג. |

| מסע לקוח ואוטומציות | מסע לקוח חכם מחבר את הנקודות בין החשיפה לרכישה, ויוצר חוויה שמובילה לתוצאות גם כשאת לא שם. |

## תהליך עבודה — 5 שלבים

### שלב 1: קריאת הקלט

**מצב א' — TIME OS:**
1. קרא את הקובץ (PDF: כלי Read; DOCX: ניתן גם לקרוא)
2. חלץ: מה הלקוח עושה, אילו בעיות/צרכים עלו, פלטפורמות שהוזכרו, אינדיקציות לתקציב
3. סכם בנקודות לפני שממשיכים

**מצב ב' — ידני:**
1. קבל מהמשתמשת את רשימת השירותים
2. אמת שכל שירות קיים ב-`services.md`
3. הצג ללקוחה את הרשימה לאישור לפני המשך

### שלב 2: התאמת שירותים

1. קרא את `../../shared knowledge/services.md`
2. בחר 2–5 שירותים לפי הצרכים שעלו
3. סדר לפי רלוונטיות (הכי חשוב קודם)
4. שירות עם "⚠️ יש להשלים" — כתוב בשדה מחיר: "מחיר בהתאם להיקף — יועבר בנפרד"

### שלב 3: יצירת קובץ JSON

שמור כ-`proposals/proposal_[שם לקוח]_draft.json`:

```json
{
  "client_name": "שם הלקוח",
  "date": "DD/MM/YY",
  "intro": "Sister Marketing היא סוכנות דיגיטל שחושבת אסטרטגיה...",
  "services": [
    {
      "title": "ניהול סושיאל (פייסבוק ואינסטגרם)",
      "lead": "ניהול סושיאל איכותי מתחיל באסטרטגיה ברורה...",
      "bullets": [
        "אסטרטגיית תוכן חודשית לאינסטגרם",
        "8 פוסטים בחודש, מתוכם עד 4 ריילס"
      ],
      "price": "עלות השירות: 3,500 ₪ + מע\"מ לחודש"
    }
  ]
}
```

### שלב 4: הפקת ה-PDF

הרץ בטרמינל:

```powershell
python "agents/proposals agent/generate_proposal.py" `
  --content "agents/proposals agent/proposals/proposal_[שם לקוח]_draft.json" `
  --output "agents/proposals agent/proposals/proposal_[שם לקוח].pdf"
```

### שלב 5: אישור ודיווח

1. דווח על נתיב הקובץ הסופי
2. הצג תקציר: שם לקוח, שירותים שנכללו, סה"כ עלות חודשית/חד-פעמית (אם ידוע)
3. מחק את ה-JSON הזמני (`_draft.json`)

## הגדרת סביבה (פעם ראשונה בלבד)

Python אינו מותקן כברירת מחדל. נדרש Python 3.11+.

1. הורד והתקן Python מ-[python.org](https://python.org) (גרסה 3.11 ומעלה)
2. הרץ בטרמינל:

```powershell
pip install -r "agents/proposals agent/requirements.txt"
```

**תלויות (`requirements.txt`):**
```
reportlab>=4.0
pypdf>=4.0
python-bidi>=0.4.2
arabic-reshaper>=3.0.0
python-docx>=1.1.0
```

## הערות טכניות (לעיון)

- פונטים: `shared knowledge/Brand book/hebrew font/static/`
- כל טקסט עברי עובר דרך `python-bidi` + `arabic-reshaper` לפני העברה ל-ReportLab
- כל עמוד תוכן = שכבת טקסט (ReportLab) ממוזגת מעל תבנית הרקע (pypdf.merge_page)
- גודל עמוד: A4 (595×842pt). אזור תוכן: y=82–720pt מלמטה
- מיזוג סופי: שער + עמודי תוכן + תנאים
