## ערכי סטטוס

| סטטוס | משמעות | פעולה הבאה |
|-------|---------|-----------|
| `ליד חם` | אחרי שיחה ראשונה, לפני הצעה | שלח הצעת מחיר |
| `נשלחה הצעה` | ההצעה יצאה | פולואו אפ אחרי 5 ימי עסקים |
| `ממתין לתגובה` | אחרי פולואו אפ, עדיין ממתינים | פולואו אפ נוסף אם צריך |

| `אושר` | הלקוח אישר — מתחילים לעבוד | קליטת לקוח |
| `נדחה` | לא התקדם | ארכיב |
| `נדחה לעתיד` | מעוניין אך לא עכשיו | תזכורת בעתיד |

## כללי פולואו אפ

- **ברירת מחדל:** 5 ימי עסקים מיום שליחת ההצעה
- **חישוב ימי עסקים:** דלג על שישי ושבת. לדוגמה: הצעה נשלחת ביום ד' 28/05 → פולואו אפ ביום ד' 04/06
- **דגל אדום 🔴:** `followup_date` עבר + סטטוס = `נשלחה הצעה` או `ממתין לתגובה`
- **דגל כתום 🟡:** `followup_date` = היום
- **לא לסמן:** לידים בסטטוס `אושר`, `נדחה`, `נדחה לעתיד`

## מבנה תיקיית לקוח בדרייב

כשלקוח מאושר, צור את המבנה הזה ב-Google Drive:

```
Sister Marketing/
└── לקוחות/
    └── [שם לקוח]/
        ├── הצעת מחיר (העתק ה-PDF)
        ├── חוזה ואישורים/
        ├── בריפים/
        ├── תוכן ופוסטים/
        ├── קמפיינים/
        └── דיווחים חודשיים/
```

**יצירת תיקיה ב-Drive:** השתמש ב-`mcp__claude_ai_Google_Drive__create_file` עם:
```json
{
  "name": "[שם התיקיה]",
  "mimeType": "application/vnd.google-apps.folder",
  "parents": ["[ID של תיקיית האב]"]
}
```

**העתקת קובץ (הצעת מחיר):** השתמש ב-`mcp__claude_ai_Google_Drive__copy_file` עם ה-ID של ה-PDF ו-ID של תיקיית היעד.

**מציאת תיקיית "לקוחות":** חפש עם `mcp__claude_ai_Google_Drive__search_files` את `"לקוחות"` עם `mimeType:'application/vnd.google-apps.folder'`. אם לא קיימת — צור אותה.

## הגדרה ראשונית — יצירת ה-Google Sheet

פעם אחת בלבד:

1. פתחי [Google Sheets](https://sheets.google.com) → צרי גיליון חדש
2. שמי אותו `Sister CRM Pipeline`
3. הוסיפי שורת כותרות (שורה 1):
   ```
   שם לקוח | איש קשר | טלפון | מייל | תחום עיסוק | מקור | תאריך שיחה | שירותים | סכום מוצע | תאריך שליחת הצעה | לינק להצעה | סטטוס | תאריך פולואו אפ | הערות
   ```
4. קבעי RTL לגיליון: File → Spreadsheet settings → Locale: Israel
5. הוסיפי Dropdown validation לעמודה L (סטטוס) עם ערכי הסטטוס מהטבלה למעלה
6. שתפי את הגיליון עם כל הצוות
